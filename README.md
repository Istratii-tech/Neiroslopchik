# Нейрослопчик

Нейрослопчик — сонный рыжий котёнок с пиксельным ухом и жетоном «НЕЙРОСЛОП» на ошейнике. Он живёт в вашем телефоне и в случайный момент выезжает слева в верхней части экрана, чтобы рассказать смешную IT-новость.

Новости для него пишет искусственный интеллект: каждый час он берёт свежие заголовки из мира технологий и превращает их в маленькие абсурдные истории — про смартфоны, ноутбуки, нейросети и гаджеты.

Все новости сгенерированы ИИ и являются вымыслом. Совпадения с реальными событиями, компаниями и людьми случайны.
